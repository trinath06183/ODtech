# Project Roadmap

> **Project:** ODtech ERP  
> **Status:** Active (Phase 8 In Progress / Planned)

---

## Completed Phases
- [x] **Phase 1: Foundation** — Core Django setup, custom user model, roles, authentication, audit middleware.
- [x] **Phase 2: Contacts & Inventory** — Contacts CRM, stock ledger, low stock alerts, warranty claims.
- [x] **Phase 3: Commercial Documents** — Quotations, Invoices, Proformas, Challans, POs, GST tax logic, multi-currency, PDF previews.
- [x] **Phase 4: Payments & Cash Flows** — Payment receipts, vendor payouts, expense workflows, aging buckets.
- [x] **Phase 5: Order Tracker** — Manufacturing orders, lots, supplier cost comparison, price approval requests.
- [x] **Phase 6: EDMS & Executive Dashboards** — Document management, OTP downloads, mobile QR uploads, financial dashboard.
- [x] **Phase 7: Security & Performance Hardening** — Query optimizations, CSRF, security headers, index tuning.
