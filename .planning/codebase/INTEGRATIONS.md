# External Integrations & Services

> **Generated by GSD Map Codebase**  
> **Project:** ODtech ERP  

---

## 1. Database Systems
- **PostgreSQL (`odtech_db`):**
  - Connected via `psycopg2-binary`
  - Managed via Django ORM migrations (`manage.py migrate`)
  - Connection pooling handled via Gunicorn worker recycling & Django connection settings

---

## 2. Google APIs & Cloud Services
- **Google OAuth 2.0:**
  - Library: `google-auth-oauthlib`, `google-auth-httplib2`
  - Integration: Secure authentication and service account credentials
- **Google Drive / Workspace:**
  - Library: `google-api-python-client`
  - Purpose: Cloud backup of commercial documents and EDMS attachments

---

## 3. Email & SMS Notifications
- **SMTP Email Service:**
  - Configured via standard Django `django.core.mail.backends.smtp.EmailBackend`
  - Sends OTP verification codes, password reset tokens, price approval alerts, and document shares
- **SMS / WhatsApp Alerts (Hook Ready):**
  - Notification hooks built into `tracker/models.py` and `users/models.py` for dispatch status updates and emergency notifications

---

## 4. Reverse Proxy & Network Architecture
- **Nginx:**
  - Proxies HTTP traffic to UNIX socket / Gunicorn port 8000
  - Handles SSL termination via Let's Encrypt Certbot
  - Serves static assets (`/static/`) directly from collected WhiteNoise files
- **Ngrok / Remote Tunnels:**
  - Used for developer preview, mobile device testing (Mobile Upload QR scan), and remote webhook handling

---

## 5. Mobile Scanner / QR Code Integration
- **Mobile QR Code Upload (`mobile_upload` app):**
  - Generates single-use signed QR tokens allowing warehouse staff or drivers to upload delivery slips, challans, or photos directly from mobile browser cameras into EDMS without requiring an active staff login
