# Technical Concerns, Debt & Known Challenges

> **Generated by GSD Map Codebase**  
> **Project:** ODtech ERP  

---

## 1. Ambiguous Category Matching in Reporting
- **Issue:** Commercial documents and EDMS categories share similar names (e.g. "Invoices" vs "Proforma Invoices"). Broad queries using `name__icontains='invoice'` inadvertently captured Proforma Invoices (`PRO`) as Purchase Invoices.
- **Status:** Resolved in `reporting/views.py` by prioritizing exact names and explicitly excluding `name__icontains='proforma'`.
- **Recommendation:** Maintain strict category IDs or explicit enum constants rather than free-form string matching.

---

## 2. Monolithic View Files
- **Issue:** Several view files are very large (e.g., `tracker/views.py` is ~127KB, `reporting/views.py` is ~55KB, `documents/views.py` is ~50KB).
- **Risk:** Increases the chance of regression when editing complex logic.
- **Recommendation:** Progressively extract business logic into service functions (e.g. `tracker/services/order_service.py`, `reporting/services/kpi_service.py`).

---

## 3. Environment Parity (Windows vs Ubuntu Production)
- **Issue:** Developers run Windows 11 with PowerShell and `py` launcher, while production runs Ubuntu 22.04 with systemd (`odtech.service`) and Gunicorn.
- **Risk:** File path separators (`/` vs `\`), line endings, and binary dependencies (`psycopg2` vs `psycopg2-binary`).
- **Recommendation:** Always use `os.path.join` or `pathlib.Path` for file system manipulation and ensure UTF-8 encoding across all template and asset files.

---

## 4. Background Tasks & Worker Process
- **Issue:** Background jobs currently rely on `django-apscheduler`. Long-running tasks like bulk PDF generation or heavy OCR could block Gunicorn web worker threads.
- **Recommendation:** For scaling, consider offloading asynchronous PDF/OCR rendering to a lightweight Celery / Redis worker queue.
