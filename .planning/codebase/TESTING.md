# Testing Strategy & Guidelines

> **Generated by GSD Map Codebase**  
> **Project:** ODtech ERP  

---

## 1. Test Framework
- **Test Runner:** Standard Django Test Runner (`django.test.TestCase` / `django.test.Client`).
- **Fixtures & Factories:** Initialized in `setUp()` or loaded via test fixtures.
- **Mocking:** `unittest.mock.patch` for external APIs (Google Drive, Email SMTP, SMS gateways).

---

## 2. Test Locations
- `documents/tests.py`: Commercial document creation, PDF generation, calculation tests, and preview endpoints.
- `tracker/tests.py`: Order workflow, lot splitting, cost approvals, status transitions.
- `users/tests.py`: Authentication, section permissions, OTP expiration and validation.
- `edms/tests.py`: Access matrix, confidential document visibility, upload security.

---

## 3. Running Tests
Run all test suites:
```powershell
py manage.py test
```

Run tests for a specific module:
```powershell
py manage.py test documents
py manage.py test tracker
py manage.py test users
py manage.py test edms
```

Run with lightweight SQLite test database:
```powershell
py manage.py test --settings=erp_project.settings.sqlite
```

---

## 4. Verification Checklist Before Deployments
1. **Migrations Check:** Run `py manage.py makemigrations --check --dry-run` to ensure all model changes have migrations.
2. **Static Files Check:** Run `py manage.py collectstatic --noinput` to verify no missing static files or syntax errors.
3. **Database Integrity:** Ensure foreign keys and nullability constraints match database models.
