# Coding Conventions & Patterns

> **Generated by GSD Map Codebase**  
> **Project:** ODtech ERP  

---

## 1. Python & Django Standards
- **Style Guide:** PEP 8 compliance with 4-space indentation.
- **Model Design:**
  - Base class: Inherit from `core.models.TimeStampedModel` for `created_at` and `updated_at` timestamps.
  - Monetary values: Always use `DecimalField(max_digits=18, decimal_places=2, null=True, blank=True)` rather than FloatField to prevent floating point inaccuracies.
  - String representations: All models define a readable `__str__` method.
  - Plural names: Explicit `verbose_name` and `verbose_name_plural` in `class Meta`.

---

## 2. Authorization & Permissions
- **View Security:**
  - Every view MUST be protected with `@login_required` or role-based check:
    - `@role_required(['Admin', 'Executive'])`
    - `@require_permission('MODULE_NAME', 'read' | 'write')`
- **EDMS Permission Mixin:**
  - EDMS views use `EDMSLoginRequiredMixin` and `PermissionService.has_document_access(user, doc, 'view'|'download'|'edit')`.

---

## 3. Financial & Data Integrity
- **Exact Category Matching:**
  - Always use exact category names or explicit exclusions when querying document categories (e.g. `exclude(name__icontains='proforma')` when retrieving standard tax or purchase invoices) to avoid conflating Proforma Invoices with Tax Invoices.
- **Atomic Operations:**
  - Use `transaction.atomic()` when performing multi-model write operations (e.g., creating a commercial document and its items, or approving a lot dispatch).

---

## 4. Frontend & Template Conventions
- **Tailwind Utility Classes:**
  - UI styled using modern Tailwind CSS utilities.
  - Modals and dynamic panels use Alpine.js or Vanilla JavaScript event listeners.
- **Form Inputs:**
  - Standardized Tailwind widgets defined via reusable constants: `TAILWIND_INPUT`, `TAILWIND_SELECT`, `TAILWIND_AREA`.
- **Modals & Drawers:**
  - Form dialogs and collapsible accordions preserve form state and handle AJAX JSON responses without full page reloads where appropriate.
