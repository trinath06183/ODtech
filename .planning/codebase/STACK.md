# Tech Stack & Dependencies

> **Generated by GSD Map Codebase**  
> **Project:** ODtech ERP  
> **Repository Path:** `ODtech/`

---

## 1. Core Runtime & Language
- **Language:** Python 3.10+ / 3.11
- **Framework:** Django 4.2+ (LTS)
- **WSGI Server:** Gunicorn 22.0.0 (running 3 worker processes in production systemd `odtech.service`)
- **Web Server / Reverse Proxy:** Nginx with SSL / Certbot (ngrok tunnel for staging / remote access)
- **Operating Systems:**
  - Production: Ubuntu 22.04 LTS (Linux x86_64)
  - Development: Windows 11 (PowerShell / py launcher)

---

## 2. Databases & Storage
- **Primary Database:** PostgreSQL 14+ / 15+ (`psycopg2-binary >= 2.9.0`)
  - Production Database: `odtech_db` on `localhost:5432`
- **Fallback / Local Database:** SQLite 3 (`erp_project/settings/sqlite.py`)
- **Static Files Storage:** WhiteNoise 6.6.0 with caching & compression
- **Media / Document Storage:**
  - Local filesystem storage (`MEDIA_ROOT`) for general assets & photos
  - Secure private EDMS root for restricted documents, certificates, and compliance files
- **Image Processing & OCR:**
  - Pillow >= 10.0.0 (image handling & thumbnails)
  - OpenCV Headless (`opencv-python-headless >= 4.8.0`) & NumPy (`>= 1.24.0`) for document scanning / auto-crop
  - PyPDF2 >= 3.0.1 (PDF metadata extraction, page counting, manipulation)

---

## 3. Security, Authentication & Scheduling
- **Brute-Force Protection:** `django-axes >= 6.0` (rate-limiting login attempts, lockout monitoring)
- **Asset Pipeline:** `django-compressor >= 4.4` (offline & on-the-fly CSS/JS asset minification)
- **Background Tasks & Cron:** `django-apscheduler >= 0.6.2` (scheduled OTP cleanup, background recurring jobs)
- **Environment Configuration:** `python-dotenv >= 1.0.0` (`.env` loading for secrets, DB credentials, API keys)

---

## 4. Google Workspace & Cloud APIs
- `google-api-python-client >= 2.100.0`
- `google-auth >= 2.20.0`
- `google-auth-oauthlib >= 1.0.0`
- `google-auth-httplib2 >= 0.1.0`
*(Used for Google Drive / Sheets / Cloud integrations and document archiving)*

## 5. Frontend & UI Stack
- **HTML:** Semantic HTML5 templates with Django Template Language (DTL)
- **CSS:** Tailwind CSS (utility classes + custom CSS in `static/css/`)
- **JavaScript:** Vanilla JavaScript (ES6+), Fetch API, Alpine.js / light micro-interactions
- **Icons & Visuals:** SVG icon sets + system emoji indicators
- **Charts & Visualization:** Chart.js / ApexCharts for Executive Financial Trends & Order Analytics
